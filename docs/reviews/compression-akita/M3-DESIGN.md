# Compression milestone 3: the shrink proof (synthesized design)

Date: 2026-10-07. Branch `claude/compression-spartan-whir` (PR #171), on top of M2 (dd8a38805).
Inputs: `m3-arena/GROUNDING.md` and the candidates `m3-arena/candidate-{a,b,c}.md`.
"est." marks an estimate; nothing here is measured yet unless it says "measured".

## Owner decisions (2026-10-07)

- **Route: our own WHIR stack** (sum-check + p3-whir 0.8 over the cubic Goldilocks extension).
  Plonky3-recursion was rejected: its Goldilocks challenge field is degree 2.
- **Targets:** final proof at most 200 KB (hard), goal 100 KB or less; native verification about
  100-400 ms on CPU; about 114 proven bits (Johnson bound); post-quantum.
- **Proof-of-work:** up to 20 bits on the last layer.
- **Keccak separator constants** of p3-challenger 0.8 accepted as fixed constants
  (`M2-DESIGN.md`, Result item 7). No other Keccak use.

## Base and grafts

**Base: candidate C.** The cross-judge scored C 22, A 18, B 15 and recommended C. My own reading
agrees. C reaches the goal with the most margin (a 2^23 witness), has the cheapest prover, keeps
M2 as it is, and makes the native verifier, the witness generator and the circuit one function.

C's design, kept:

- **One shrink layer, one commitment.** SuperSpartan (ePrint 2023/552) over a CCS
  `f(z) = (X·z)^7 + Σ_{i<3} (A_i·z)∘(B_i·z) − C·z`. Each Poseidon2 S-box is one row. The witness
  `w` (2^23 Goldilocks cells, est. 80-85% full) is committed once with p3-whir 0.8: rate 1/64,
  PoW 20, Johnson bound, folding schedule `ConstantFromSecondRound(5, 4)` (the first fold of 5
  removes one WHIR round at 2^23).
- **One verifier, written once** over a `Backend` trait. `Native` is the plain final verifier
  (`verify_final`). `Recorder<Witness>` records the rows and the witness. `Recorder<Evaluate>`
  re-runs the program on a zero input and streams the glue matrix MLEs at the sum-check point.
  Generic code never branches on values; values enter only through checked hints.
- **Structure split by size.** About 32.5k Poseidon2 permutations (full Merkle paths per query)
  sit in uniform blocks whose matrix MLEs have closed forms (a diagonal carry DP over the block
  index). Everything else ("glue", about 1M rows) is regenerated by the native verifier.
- **Our own generic copy of the p3-whir 0.8 verifier** for our profile. It becomes the native
  verifier of M1/M2 openings too; p3's `verify_at` stays as a test oracle.
- **A key-only final verifier.** `CompressionKey` holds the layer-1 key, the fold constants the
  layer-0 replay needs, and the shrink shape counts. A chain node needs no package and no files.
- **Budget:** the remainder after the fold error is split in two equal halves: M2 layer 1 and the
  shrink layer each get 2^-117.05 at a 114-bit minimum.

Grafts:

1. **Exact PiRLC (from A), replacing C's random-point check.** The parent claim is computed
   exactly as `Σ_i ρ_i ⋆ source_i` over 37 ring vectors per source. Each ring product is a
   template: 107 evaluation product rows plus 54 output rows (interpolation and reduction mod
   Φ81 are fixed linear maps), placed in uniform slots with a closed form. 629 products × 107 ≈
   67k product rows. No new Fiat-Shamir step, no change to how `verify_final` checks PiRLC.
2. **Deferred placement (from A).** A proof word gets a column at its first structural use; when
   that use is a Poseidon2 input lane, the lane is its home and no copy row is needed. A linear
   combination becomes a column only when that lowers the nonzero count.
3. **"Where validation lives" (from A).** The list of places where the circuit differs from the
   native check, each stricter or equal: full Merkle paths instead of pruned multiproofs; the
   p − 1 uniform-bits sample is rejected instead of resampled (completeness gap ≈ 2^-54, no
   soundness effect); native zero-skips become computed zero terms.
4. **WHIR counts read from p3 (from A).** Query counts, OOD samples, folding and domains come
   from p3's public `WhirConfig` accessors, never recomputed by us.
5. **Duplex details and the hint contract (from B).** Exact p3 `DuplexChallenger` semantics
   (overwrite absorb, output pop order, length handling); `hint` returns unconstrained cells
   that the caller must constrain, in one visible place.
6. **Reserve levers (from B, only if measured verifier time exceeds 400 ms):** predecessor-linked
   block families that move sponge and Merkle chaining into the uniform part, and regeneration
   on several threads with section offsets pinned in the key counts.
7. **One public proof type (from A and B).** `Prover::finish_with_spartan` returns the final
   shrink proof. The 1.6 MB M2 proof becomes internal.

Rejected: B's R1 (moves the M2 statement boundary; its motivation was a wrong cost figure) and R2
(+5 GB M2 memory for a circuit that already fits); A's R1CS (2^25 witness, about 3× prover time
and memory, proof at the goal edge after the fold-round correction); two shrink layers (needs a
fully uniform inner layer; saves about 10 KB against a design that already meets the goal);
holography (a second opening of 85-120 KB).

Corrections by the judge, adopted: an exact PiRLC costs about 67k product rows, not 1.8M; a
straight-line extrapolation of the WHIR table misses the extra fold round at 2^23 and above
under `Constant(4)`; setup leaves already carry full paths (about 5.2k permutations in-circuit);
`plan_stacked_layout` is public (only `restore_paths` of `p3-merkle-tree` is crate-private).

## Public API (nightstream)

```rust
let setup = prover.compression_setup(dir)?;                       // M2, unchanged (once per circuit)
let key = verifier.compression_key()?;                            // or a pinned copy, about 3 KB
let proof: FinalProof = prover.finish_with_spartan(&envelope, &setup)?;  // M2 + shrink, ≤ 100 KB
nightstream::verify_final(&key, &expected_state, &proof)?;        // key only, about 120-300 ms
```

`FinalProof` is the shrink proof (strict canonical bytes). `CompressionKey` gains the fold
constants and the shrink shape.

## Soundness map (summary)

| Term | Bound |
| --- | --- |
| Fold chain | `Params::fold_error_bits` (≈ 2^-114.4) |
| M2 layer 1 | ≤ 2^-117.05 (`Relation::new`) |
| Shrink: zero-check τ, outer sum-check (degree 8), ρ batching, inner sum-check | about 2^-160 to 2^-180, each charged over WHIR's candidate list |
| Shrink WHIR | ≤ 2^-118.05 (p3 report incl. the terms above) |
| Total | ≤ 2^-114 |

Composition: the shrink argument is knowledge-sound for the CCS; a satisfying witness contains a
final proof that the program accepts; every check of the native verifier is a row; hints are
constrained; bits are canonical. M2's Fiat-Shamir challenges are recomputed in the circuit with
the same Poseidon2 (the standard recursion heuristic).

## Implementation slices (each with its own tests, ≤ 300 s each)

0. **Spike.** Measure p3-whir at 2^23, rate 1/64, PoW 20, 118 bits, schedules constant 4 and
   [5,4,…] (bytes, time, peak RSS). Count the full-path permutations of the production M2
   verifier.
1. **Circuit core** (`neo-spartan/src/circuit/`): `Backend`, `Native`, `Recorder` (witness and
   evaluate modes), forms and rows, algebra helpers, `Duplex`, `FoldTranscript`, leaf sponge,
   Merkle path, the Poseidon2 block and ring-product templates. Tests: parity with p3's
   permutation, challenger and MMCS and with neo-transcript; recorded rows hold for honest values
   and break under mutation; the row stream of a zero input equals that of an honest input.
2. **Generic WHIR verifier** (`neo-spartan/src/whir/`). Tests: accepts and rejects exactly what
   p3 `verify_at` does on several plans, rates, PoW values and schedules.
3. **Generic layer 1** (`verify.rs` and the verifier halves). Tests: every existing test passes
   on `Native`; toy circuits are satisfiable on honest proofs and not on mutated ones.
4. **Generic final verifier** (nightstream: statement, state hash, PiDEC parent, PiCCS replay,
   exact PiRLC, handoff, `FoldKey`, `CompressionKey`). Tests: trace parity with neo-reductions;
   key-only verification equals package verification; mutations reject.
5. **Shrink layout** (regions, templates, diagonal DP, closed forms, glue mapping). Tests: closed
   forms equal brute force; streamed glue equals an explicit evaluation.
6. **Shrink argument** (SuperSpartan sum-checks, `prove`, `verify`). Tests: toy programs prove
   and verify; every mutation rejects.
7. **nightstream integration.** API above; toy end-to-end; ignored production test with bytes,
   times, verifier time and peak RSS.
