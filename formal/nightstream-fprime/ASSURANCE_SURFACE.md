This document identifies the final row theorems and their scope. The selected
Nightstream Goldilocks profile uses `b = 2`, `k_rho = 16`, 17 sources, 16 children,
4 matrices, 28 rounds, and Poseidon2 binding. A successful build checks the
stated conclusions under their stated hypotheses.

subsequent checkpoints below.

**What is proved locally, and what remains explicit.**

- Low-norm invertibility (SuperNeo Theorem 4, `z = 3`) is proved by `Spec.Phi81StrongSet.lowNormInvertibility` ([source](NightstreamFPrime/Spec/Phi81StrongSet/LowNormInvertibility.lean)). Only the Mathlib-free Spec core (`Phi81StrongSet.productionSet_strong`, `PiRLCAlgebra.Challenge`, `PiRLCAlgebra.ForkStrongSet.strongSetUnits`) takes `LowNormInvertibility` as a parameter; the Lifecycle and Export consumers supply the proof, so no security theorem carries it.
- Named Poseidon2 collision events remain explicit. Treating them as negligible requires the applicable cryptographic security premise. The approved [public-seed MSIS assumption](../../docs/reviews/nightstream-fprime-requirements/PUBLIC_SEED_MSIS_ASSUMPTION.md) was specifically for the frozen ChaCha20-generated matrix and strict norm below `8TB`; it is stronger than a setup-average or uniform-matrix assumption. For the current SHAKE128 matrix, `production_binding_lt_solver` ([source](NightstreamFPrime/Export/Stage1/SetupDistribution.lean)) proves in the ideal model that an ordinary binding collision gives an MSIS solution for a uniform matrix, with error below `2^-190`; it has no form for the kernel vectors of relaxed collisions. SHAKE128 as a random oracle and uniform-matrix MSIS stay explicit premises ([`SECURITY_ARGUMENT.md`](../../docs/reviews/ajtai-key-expander/SECURITY_ARGUMENT.md)). `Export.Stage1.Poseidon2HashChainV1Setup.productionBindingCollision_to_shortKernel` and `Export.Stage1.Poseidon2HashChainV1Setup.productionRelaxedBindingCollision_to_shortKernel` turn an ordinary or a `(2B, C)`-relaxed production binding collision into a short kernel vector at the `8TB` norm, and `Export.Stage1.Poseidon2HashChainV1Setup.productionShortKernel_to_approvedMsis` extends it to the fixed-seed instance with the earlier approved dimensions. Two different extracted witnesses for one statement (the random-oracle `collisionChance`) give a relaxed binding collision and such a kernel vector (`Lifecycle.RandomOracleBinding.rerun_shortKernel`). No numerical hardness bound follows from this approval.
- `Spec.AjtaiSetupV1.Prefix.extendShortKernel` preserves a nonzero short integer kernel when a same-seed key prefix is extended by zero blocks. Padding starts after the smaller complete carrier. This is the deterministic prerequisite for retaining the existing hardness premise after the proposed unused-allocation removal; it changes no package width or pin and proves no hardness.
