# Soundness Audit Report — `neo-fold-clean` (HyperNova Construction 2 over Neo CCS folding, ell=1, multi/parallel K-fold)

## Verdict

Construction 2 and the F' augmented circuit are **sound for the ell=1, single-F'_j, multi-K-fold build they target**, with **zero critical and zero high-severity findings**. The load-bearing mechanisms are correct and adversarially robust: the in-circuit NIFS.V (Π_CCS split-NC sumcheck → Π_RLC fold → Π_DEC strict recomposition) is recomputed from authoritative wires rather than trusted; the running accumulator `U_i` is bound into `x_out` via a full CE-claim digest recomputed in-circuit (not a commitment-only projection), so re-digest-upward attacks fail; the base case installs a genuine empty/u_perp accumulator and cannot be taken at `i>0`; the terminal decider closes the full SuperNeo R2 (CE) relation against the opened final children with a strict `|Z|<b` norm. Poseidon2-only is maintained throughout protocol-binding paths. The **one substantive finding (medium)** is a *layering* gap: cross-step app-state connectivity (HyperNova's recursive link `u_i.x == enc_inst(prior_x_out)`) is enforced in-relation only by the audit decider R1CS, not by the production folded F' image nor by the O(1) `verify_uncompressed`. Two practical caveats *block full reliance today*: (1) the Spartan compression/decider layer is an unimplemented fail-closed placeholder (`Err(Unsupported)`), so no shipped compact verifier currently discharges the cross-step obligation in-relation; (2) the constant-cost `verify_uncompressed` is explicitly documented as *not* the compressed-consumer soundness contract for stateful chains. Within the implemented native/R1CS-audit surfaces, the protocol is sound.

## Construction 2 & F' soundness

- **IVC carrier — sound.** The base/recursive branch is tag-driven natively (`FoldProofVariantMismatch`) and structurally impossible to spoof in-circuit (base pins `chunk_count_in==0`; recursive proves it nonzero via an in-circuit inverse). Finalization folds the trailing `latest` so the running handed to the decider covers every batch, and a finalized proof with no terminal fold is rejected (`MissingTerminalFoldProof`).
- **Base case / u_perp — sound.** `i=0` installs `AccumulatorHandle::empty()` (genuine trivial CE instance, no parent), enforces `z_0==z_i` and zero counters in-circuit, and the decider pins base seeds to preprocessing-derived constants. No way found to forge the first step or skip the first real fold.
- **x_out hash-chain binding — sound for ell=1, with a flagged latent gap.** `state_x_out` absorbs `vk_fs`, counters, `z_{i+1}`, optional `semantic_acc`, and `construction2_acc = U_{i+1}` (full running digest). The native preimage and in-circuit gadget agree field-for-field (verified across `digest.rs`, `digest_circuit.rs`, `recursive_plan.rs`). `z_0`/`structure` are bound transitively through `vk_fs_digest`. **pc is omitted** and only pinned to `TRIVIAL_PC` out-of-band — sound at ell=1, but a hard landmine for any future multi-pc (ell>1) frontend (the code itself flags this at `digest.rs:708-709`).
- **In-circuit F' verifier (recompute, not trust) — sound where realized.** `paper/f_prime/r1cs.rs` runs the full NIFS.V in-circuit, recomputes the input running digest and pins `acc_digest_in == digest(running)`, recomputes `prior_x_out` from authoritative state-in wires, binds every fresh `u_i.x == enc_inst(prior_x_out)` (recursive link), and recomputes `x_out` from the freshly folded state. The delayed `acc_digest_out` free witness is fully closed downstream (state-link + next-step recompute + CE-continuity + terminal pin). **The gap (finding R1CSFP-1):** this in-circuit recursive link / cross-step state-link lives only in the *audit* decider R1CS (`engine/decider.rs`), **not** in the *production* folded F' image (`frontends/f_prime/structure.rs::emit_shell_rows`), so the O(1) `verify_uncompressed` and the native replay walk do not re-enforce intermediate connectivity in-relation.

## Critical & High

**None.** No critical or high-severity soundness defect was found in the focus files. The in-circuit NIFS.V, the three Π reductions + split-NC circuit, the decider/compress seam, digest+transcript binding, the gadgets, and lifecycle prove/verify are all at least as strict as their native counterparts.

## Medium

### R1CSFP-1 — Cross-step semantic-state connectivity enforced only by the audit decider R1CS, not the production folded F' image / O(1) verifier

- **Where:** `frontends/r1cs_f_prime/compiler.rs:164-174,437-470`; `frontends/f_prime/structure.rs:798-973` (`emit_shell_rows` — no `prior_x_out` reconstruction / `fresh.x` link); `lifecycle/verify.rs:204-262`; `engine/decider.rs:944-957` (`enforce_state_link`); `paper/f_prime/r1cs.rs:689-743` (`prior_x_out` recompute + fresh.x link).
- **Paper invariant:** HyperNova Sec 6.3 Construction 2 step 4.b / App H.3 Eq(16),(18) — FP-HASH-CHAIN-INPUT-BINDING / FPRIME-IN-CIRCUIT-VERIFIER-RECOMPUTE: F' must in-circuit recompute prior `x_out` from `(i, z0, z_i, U_i, semantic state)` and check `u_i.x == enc_inst(prior_x_out)`; disconnected/spliced prior state must fail *the relation*, not just prover code.
- **Failure mode:** The production `emit_shell_rows` binds only *intra-step* facts (`semantic_state_digest_in == H(state_in_app_vars)`, `new_semantic_state_digest == H(state_out_app_vars)`, base anchor). It contains no in-circuit NIFS.V, no `prior_x_out` recompute, and no row forcing step `i+1`'s `state_in_app_vars` to equal step `i`'s `state_out_app_vars`. `verify_uncompressed` re-runs only the terminal fold and threads the State coordinate forward without ever requiring intermediate connectivity; the native walk (`paper::decider::validate_witness`) never inspects intermediate F' image witnesses. The prover-side guard (`SemanticStateInputMismatch`, mirrored in `lifecycle.rs:140-150`) is usability-only. So a hand-rolled prover that bypasses `compile_chunk` can build a chain whose intermediate F' images each satisfy their own CCS but whose app-state is *not* threaded, and both `verify_uncompressed` and the native walk accept it.
- **Why bounded (medium, not high):** This is the documented interim layering. `verify.rs:60-74` disclaims `verify_uncompressed` as the compressed-consumer soundness contract; the closing relation already exists, is correct, and is tested in `engine::decider` (it *does* pin `semantic_state_digest` wire-to-wire and reconstruct the recursive link). The teeth: (a) `lifecycle/mod.rs` labels `verify_uncompressed` "Production (non-replay IVC)" and `verify.rs:78-81` claims terminal Π_CCS "transitively grounds the chain" — incomplete for cross-step app-state because the production F' CCS lacks the recursive link, so the backward induction is not carried; (b) the path that would close it (`compress`/`decider::prove`) returns `Err(Unsupported)` today, so no shipped verifier enforces cross-step connectivity in-relation.
- **Suggested fix (smallest first):**
  - **(A) Documentation-truth (minimal):** tighten `verify.rs:78-81` to state explicitly that for `SemanticStateMode::Stateful`, `verify_uncompressed` does NOT enforce cross-step app-state connectivity / the recursive link `u_i.x == enc_inst(prior_x_out)`; that obligation is carried only by the decider R1CS (`enforce_state_link` + `enforce_f_prime_recursive_step_circuit`) and must be discharged by the (unimplemented) Spartan decider before a consumer relies on stateful-chain soundness. Mirror the caveat on the `lifecycle/mod.rs` "Production (non-replay IVC)" label.
  - **(B) In-relation fix for the native authority path:** in `paper::decider::validate_witness` (or `paper/f_prime/native.rs::verify`), thread the previous step's outgoing `semantic_state_digest` and assert, for Stateful mode, `semantic_state_digest_in_{i+1} == new_semantic_state_digest_i` wire-level, surfaced as a dedicated `SemanticStateLinkBroken` error. Add a regression that hand-builds an `UncompressedAudit` with a broken link and asserts the new error (must fail before the fix). Full in-circuit closure for the O(1) path requires moving the recursive-link/state-link rows from `paper/f_prime/r1cs.rs` into the production `emit_shell_rows` (folding `enc(F')`) — the larger Construction-2 work the `decider.rs` header already flags as future.

- **(low) Fresh Π_CCS-output X "tail" lanes of the last active column are unconstrained until the terminal decider closes them** — intermediate steps absorb un-pinned values into the digest; recommend zero-pinning the tail at the Π_CCS output.
- **(low) `state_x_out` Stateless/Stateful mode not bound into `vk_fs_digest`** — no cross-mode domain separation; inert because mode is verifier-owned `pub(crate)`.
- **(low) Dead/footgun gadget surface:** `enforce_norm_check_b2` (hardcoded b=2), `enforce_sumcheck_walk` (transcript-less), `enforce_mux_var` (selector not bit-constrained), and `digest::label_digest` (no callers) are exported but production-unused — gate behind `cfg(test)` or delete per the lean-codebase rule.
- **(low) `pre_fold_acc_digest` emits a `[0u8;32]` sentinel** for malformed non-empty/no-parent running instead of a hard `Err` — safe via downstream mismatch, but a direct error would be clearer.
- **(low) In-circuit y_ring chi_r tensor parity with the native evaluator is convention-matched, not a shared codepath** (`decider_ce_relation/evaluation.rs` vs `verify.rs`) — maintenance hazard; parity tests must stay mandatory.
